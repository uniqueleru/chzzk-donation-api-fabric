# CHZZK Donation API — Fabric 1.21.1

치지직 후원을 다른 Fabric 모드에서 사용할 수 있게 하는 **독립형 라이브러리 모드**.

- Minecraft Java **1.21.1**, Java **21**, Fabric Loader **0.16.14 이상**, 1.21.1용 Fabric API 필요.
- 각 마인크래프트 실행 환경이 치지직에 직접 접속. 이루의 서버, 별도 중계 API, Tailscale, Python 위젯 서비스, OBS 실행 불필요.
- **전용 서버 / 싱글플레이 내장 서버** 지원. 전용 서버 사용 시 이 API 자체는 클라이언트 설치가 필수가 아님. 소비 모드의 설치 조건은 별도.
- 게임 효과를 직접 추가하지 않음. 다른 모드가 `RECEIVED` 이벤트를 구독해 효과를 구현.
- 네이버/치지직 공식 SDK가 아님. 기존 OBS 위젯에서 사용하는 비공식 채팅 수신 경로에 의존.

## 설치

1. 해당 인스턴스의 `mods/`에 배포 JAR와 1.21.1용 Fabric API를 넣는다.
2. 전용 서버를 시작하거나 싱글플레이 월드를 연다.
3. 자동 생성된 `config/chzzk-donation-api.json`을 수정한다. 초기 설정은 연결 대상이 없는 안전한 빈 목록이다.
4. 서버 콘솔 또는 OP/치트 권한으로 `/chzzkdonation reload`, `/chzzkdonation status`를 실행한다.

```json
{
  "version": 1,
  "bindings": []
}
```

방송인 한 명의 연결 항목 예시 (**설명용 자리표시자이므로 실제 값으로 교체해야 한다**):

```json
{
  "id": "streamer-a",
  "playerUuid": "해당 서버에서 사용하는 정규 UUID",
  "sourceHash": "공식 OBS 채팅 위젯 주소의 32자리 소스 값",
  "enabled": true
}
```

- 이 항목을 `bindings` 배열에 추가한다. 최대 32명이며 ID/UUID/소스 값은 각각 중복할 수 없다.
- `sourceHash`는 **치지직 채널 ID가 아니라 공식 OBS 채팅 위젯 주소의 소스 값**이다. 주소 전체가 아니라 32자리 소문자 16진수 부분만 넣는다.
- UUID는 해당 서버의 실제 플레이어 UUID를 사용한다. 접속 후 서버의 `usercache.json` 등에서 확인할 수 있다. 정품 인증 서버와 오프라인 서버의 UUID는 다를 수 있다.
- `id`는 영문/숫자/밑줄/점/하이픈으로 된 관리용 이름(1~48자). 공개 이벤트에도 전달되므로 비밀 값을 사용하지 않는다.
- 설정은 운영자만 관리한다. 소스 값을 안다는 것이 방송 계정 소유권 인증을 뜻하지 않으므로, 방송인의 동의를 받아 등록한다.
- 잘못된 설정으로 리로드하면 기존 연결 설정을 유지한다. 설정 파일을 삭제해서 초기화하는 대신 먼저 백업한다.

## 명령어

OP 권한 레벨 2 이상 필요. 싱글플레이는 치트 권한이 필요하다. 콘솔에서는 `/`를 생략한다.

- `/chzzkdonation status` — 연결 상태 및 처리/누락 카운터.
- `/chzzkdonation reload` — 설정 재검증 후 연결 재구성.
- `/chzzkdonation test <접속한 플레이어> <양의 정수 금액> [메시지]` — 명시적인 TEST 이벤트. 실제 결제 없음.

**TEST는 `RECEIVED`를 호출하지 않는다.** 소비 모드가 `TEST`도 따로 구독해야 테스트 효과를 볼 수 있다. 라이브러리만 설치하면 몹/아이템 효과가 없는 것이 정상이다.

## 처리 정책과 한계

- 방송인이 후원 수신 시점과 전달 시점에 같은 게임 접속 세션으로 온라인이어야 이벤트를 전달한다. 미접속·퇴장·재접속 사이의 후원을 나중에 몰아서 실행하지 않는다.
- 연결 중단 동안 치지직에서 놓친 후원을 소급 수집하지 않는다. 월드/서버가 꺼지면 이 모드의 수신도 멈춘다.
- 알려진 실시간 후원 형식만 수신한다. 금액/식별 정보가 불명확하면 임의로 추측하지 않고 버린다.
- 중복 확인 이력은 월드 안의 `chzzk-donation-api/seen-events.jsonl`에 저장한다. 파일 확장자와 달리 내부 형식은 버전 헤더가 있는 전용 TSV이다. 직접 편집하지 않는다.
- 중복 방지 범위는 보관 기간 7일/최대 50,000개 이력 안이다. 용량·네트워크·디스크 오류 시 데이터 전달보다 안전한 누락을 우선한다.
- **결제 정산 시스템이나 완전한 exactly-once 실행을 보장하는 시스템이 아니다.** 기록 후 게임 효과 실행 전에 크래시하면 효과가 누락될 수 있다. 소비 모드도 중요한 지급의 멱등성을 자체 구현해야 한다.
- 월드/설정 백업은 민감 자료로 다룬다. 소스 값은 게임 클라이언트, 채팅, 공개 저장소에 올리지 않는다.
- 수신 문구/닉네임은 신뢰하지 않는 입력이다. 명령어 문자열에 그대로 삽입하지 않는다.
- 치지직 프로토콜/접근 정책 변경 시 연결 또는 인식이 중단될 수 있다. 배포 전 플랫폼 이용 조건을 확인한다.

## 개발자

[API 문서](docs/API.md), [소비 모드 예제](examples/ChzzkDonationConsumerExample.java), [검증 범위](docs/VERIFICATION.md)를 참고한다.

```bash
# Java 21 환경
bash gradlew clean test build
# Windows
# gradlew.bat clean test build
```

배포 JAR는 `build/libs/`의 **sources가 붙지 않은 JAR**이다. `src/qa`는 테스트 전용 모드이며 배포 JAR에 포함하지 않는다.

이 프로젝트는 운영 서버에 자동 배포하지 않는다. 테스트/검증 로그는 `artifacts/qa/`, 공유용 버전 패키지는 `exports/`에 둔다.
